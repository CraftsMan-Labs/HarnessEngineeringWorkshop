# Software Hacktory deck

Slide sources stay HTML fragments. Two ways to build them:

- **Python** — one-file `static.html` (open in a browser, no install)
- **Vite + Vue** — what Vercel builds (`index.html` is the Vite entry)

## Layout

```
deck/
  build.py              # stdlib builder (no deps)
  static.html           # generated by build.py
  index.html            # Vite entry
  assets/               # symlink → public/assets
  public/assets/        # logos, images
  src/
    template.html       # Python document shell
    App.vue             # Vue shell + slide inject
    assemble.js         # Vue labels + footer numbers
    framework.css
    deck.css
    deck.js
    slides/
      01-cover.html
      …
```

Each file under `src/slides/` is one `<section class="slide …">`. Filename order is slide order (`01-…`, `02-…`).

## Edit a slide

1. Open the fragment, e.g. `src/slides/03-spec-reality.html`.
2. Keep exactly one footer placeholder: `{{N}} / {{TOTAL}}`.
3. Rebuild (Python) or refresh Vite.

Do **not** hand-edit `static.html` — it is overwritten by the builder.

## Python

```bash
python3 deck/build.py            # write static.html
python3 deck/build.py --watch    # rebuild on source changes
python3 deck/build.py --check    # fail if static.html is stale
```

Open `deck/static.html` (`file://`) or serve the `deck/` folder.

## Vite / Vercel

```bash
cd deck
npm install
npm run dev
npm run build
```

Import the repo in Vercel. Set **Root Directory** to `deck`. Leave Framework Preset as Vite (auto). No `vercel.json`.
